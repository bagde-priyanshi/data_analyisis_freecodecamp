# Data Analysis with Python Projects

This repository contains the projects completed as part of the **Data Analysis with Python** certification. These projects focus on working with datasets, performing data cleaning and statistical analysis, and creating clear visualizations using Python libraries such as Pandas, NumPy, Matplotlib, and Seaborn. 

## Overview

The main goal of these projects is to build practical skills in data analysis by solving real-world style problems. The work includes matrix-based statistical calculations, dataset exploration, filtering and cleaning data, and creating graphs to identify trends, patterns, and insights. 

## Projects Included

### 1. Mean-Variance-Standard Deviation Calculator
Built a Python function that takes a list of 9 numbers, converts it into a 3 x 3 NumPy array, and returns the mean, variance, standard deviation, maximum, minimum, and sum across rows, columns, and the flattened matrix.

### 2. Demographic Data Analyzer
Analyzed an adult census dataset using Pandas to answer questions related to race, education, salary, work hours, and country-based comparisons.

### 3. Medical Data Visualizer
Worked with medical examination data to clean the dataset and generate visual insights related to health indicators such as body measurements, cholesterol, glucose levels, and cardiovascular conditions.

### 4. Page View Time Series Visualizer
Visualized forum page view data using line charts, bar charts, and box plots to understand long-term growth, monthly patterns, and seasonal trends.

### 5. Sea Level Predictor
Analyzed historical sea level data and used linear regression to predict future sea level rise through the year 2050.

## How to Run

1. Clone the repository.
2. Install the required libraries:
   ```bash
   pip install numpy pandas matplotlib seaborn scipy
   ```
3. Open the folder of the project you want to run.
4. Make sure the required dataset file is present in that project folder.
5. Run its `main.py` file.

Example:

```bash
cd Sea-Level-Predictor
python main.py
```
